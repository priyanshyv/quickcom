Payments chaos lab

Five things real payment gateways do to you. Each button runs the whole story for real: an order, the mock gateway, signed HTTP webhooks, the outbox, the queue and the SMS consumer. Run it with the naive design (/webhooks/payment/naive: no signature, no dedupe, no state machine, no reconciler) or the right one, then the lab checks the damage: money, stock, order status and SMS. Calls POST /admin/lab/payments.
